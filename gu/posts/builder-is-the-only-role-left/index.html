જૂની prestige system એ દૂરી ને ઇનામ આપ્યું

લાંબા સમય સુધી companies એ એક જુદા પ્રકારના માણસને ઇનામ આપ્યું: જે કામથી દૂર ઊભો હોય, જે કામ કરનારા ને coordinate કરે, પોતાની status ને ઉપરના layer ની ભાષામાં translate કરે, અને execution થી દૂર થઈ legitimacy ભેગી કરે. આ ખરાબ ઇરાદાથી નહોતું થયું. context ભેગો કરવો મોંઘો હતો, coordination દુર્લભ હતી — એટલે scaled company ને translators, routers, reviewers, summarizers ની જરૂર હતી, coherence ટકાવી રાખવા. Code લખનારો, code ને roadmap update માં convert કરનારા ની નીચે — જ્યારે ઉપરવાળાને code ની જ જરૂર ન રહી. આ ladder ક્યારેય સુંદર ન હતી, પણ administratively useful હતી. હવે એ usefulness ઘસાઈ રહી છે.

જ્યારે context ભેગો કરવો, move કરવો, act કરવો સસ્તો બને — ત્યારે pure coordination ની value ઘટે. Technician જે ગાડી finish કરે કારણ family ને જોઈએ. Inside-sales operator જે customer ને call back કરે કારણ પહેલો જવાબ problem solve ન કર્યો. Engineer જે system ને fix કરે outage public થાય એ પહેલાં.
